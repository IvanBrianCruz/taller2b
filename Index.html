Conceptos clave y consejos para el taller

        
Ideas claras para recordar durante la práctica y evitar trabas comunes.

      


      

        

          
¿Qué es un commit? (Punto de guardado)

          

            Hacer un commit es como hacer un punto de guardado en un videojuego:
            dejás registrada una foto estable del avance antes de probar algo nuevo.
          

          

            Tip de programador: hacé commits chicos y claros (por ejemplo, "Agrega encabezado HTML" o "Corrige estilos de tarjeta") en lugar de esperar a tener todo terminado.
          

        


        

          
Consejos prácticos para la clase de 40 min

          
    
            
  • Revisá el correo global: usá el mismo email con el que creaste la cuenta de GitHub al configurar git config --global user.email.
    • 
            
  • Verificá la carpeta: antes de correr comandos Git en la terminal de VS Code, asegurate de estar parado dentro de la carpeta del proyecto.
    • 
            
  • Atento a la rama: fijate si tu repositorio usa main o master al hacer pull o push.
    • 
            
  • Cierre rápido en Vercel: iniciá sesión con GitHub, importá el repo y desplegá con los valores por defecto sin tocar configuraciones.
